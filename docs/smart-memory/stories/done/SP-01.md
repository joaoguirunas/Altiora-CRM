# Story SP-01: Adicionar download de template em XLS além de CSV no Sends Pro

## Objetivo
Permitir que o usuário escolha entre baixar o template de importação em CSV ou XLS no módulo Sends Pro (Disparos), cobrindo os 4 tipos de lista (Recomendação, Pessoal, Evento, Network).

## Acceptance Criteria
- [ ] AC1: Botão "Baixar template de {tipo}" em `src/components/disparos/ImportListaTab.tsx` oferece seletor com as opções **CSV** e **XLS** antes de baixar
- [ ] AC2: Ao escolher XLS, é gerado um arquivo `.xlsx` válido (via biblioteca `xlsx`) contendo cabeçalho e linha de exemplo corretos para o tipo selecionado (Recomendação, Pessoal, Evento, Network)
- [ ] AC3: Ao escolher CSV, o comportamento atual é preservado integralmente (mesmo cabeçalho, mesma linha de exemplo, mesmo nome de arquivo `template_{tipo}.csv`)
- [ ] AC4: Ambos os formatos cobrem os 4 tipos de lista, usando a mesma fonte de verdade (`TIPO_CONFIG.csvHeaders` / `csvExample`) — sem duplicar definição de colunas
- [ ] AC5: Nenhum outro arquivo do projeto é alterado fora de `src/components/disparos/ImportListaTab.tsx`

## Escopo

**IN:**
- Adicionar UI de seleção de formato (CSV / XLS) no fluxo de download em `ImportListaTab.tsx` (passo `state === 'upload'`, próximo ao botão atual de "Baixar template")
- Implementar geração de XLSX em `downloadTemplate()` usando a biblioteca `xlsx` (já instalada — verificar `package.json`)
- Manter assinatura e comportamento do CSV existente
- Aplicar a todos os 4 tipos: Recomendação, Pessoal, Evento, Network

**OUT:**
- Alterar parsing/import (`FileUploadZone.tsx`, `useParseImportFile.ts`) — já aceitam CSV/XLSX/XLS
- Mudar headers, exemplos ou semântica das colunas dos templates
- Tocar em outros componentes do módulo Sends Pro
- Adicionar formato XLS legado (`.xls` binário) — gerar **`.xlsx`** moderno via `xlsx` é suficiente

## Contexto Técnico

**Arquivo único alterado:** `src/components/disparos/ImportListaTab.tsx`

**Estado atual relevante:**
- `downloadTemplate(tipo: TipoLista)` em `ImportListaTab.tsx:96-108` gera apenas CSV via `Blob` + `URL.createObjectURL`
- `TIPO_CONFIG` (linhas 31-56) define `csvHeaders` e `csvExample` para cada um dos 4 tipos — fonte de verdade única, **reutilizar como está**
- Botão atual: `ImportListaTab.tsx:301-310` (variant outline, dashed, ícone `FileDown`)
- O parser de upload (`useParseImportFile.ts` + `FileUploadZone.tsx`) já lida com CSV/XLSX/XLS — não precisa de mudança

**Dependências:**
- `xlsx` já instalada no `package.json` (verificar versão antes de implementar)
- API esperada: `XLSX.utils.aoa_to_sheet([headers, example])`, `XLSX.utils.book_new()`, `XLSX.utils.book_append_sheet()`, `XLSX.writeFile()` ou `XLSX.write()` + `Blob`

**Sugestão de UX (não vinculante, dev-ux pode refinar):**
- Trocar o botão único por um par de botões inline (CSV / XLS) ou usar um `DropdownMenu` no botão "Baixar template" com as duas opções
- Manter o ícone `FileDown` e o estilo dashed atual

**Constraints:**
- Não duplicar definição de colunas — `TIPO_CONFIG.csvHeaders` e `csvExample` permanecem fonte única
- Nome do arquivo XLS deve seguir o mesmo padrão do CSV: `template_{tipo}.xlsx` (lowercase, espaços → `_`)
- Não introduzir dependência nova (xlsx já existe)
